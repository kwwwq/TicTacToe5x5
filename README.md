Крестики-нолики 5 на 5
Описание проекта

«Крестики-нолики 5 на 5» — логическая игра, реализованная на языке Python с использованием библиотеки PyQt6. Игроки по очереди ставят крестики и нолики на игровое поле размером 5×5 клеток. Побеждает игрок, первым собравший 4 своих символа в ряд.

Возможности:
Игра против компьютера.
Локальная игра для двух игроков.
Выбор стороны при игре с компьютером.
Проверка занятых клеток.
Автоматическое определение победителя.
Подсветка победной линии.
Досрочное определение ничьей.
Кнопка «Сдаться».
Статистика партий за сессию.
Графический интерфейс пользователя на основе PyQt6.

Правила игры

Первыми всегда ходят крестики. За один ход игрок ставит свой символ в любую свободную клетку.

Побеждает игрок, который первым выстроит 4 символа подряд по горизонтали, вертикали или диагонали.

Если всё поле заполнено или ни один игрок уже не может собрать 4 в ряд, объявляется ничья.

Обозначения:

X — крестик.
O — нолик.
Зелёные клетки — победная линия.

Требования
Python 3.10 или выше
PyQt6

Запуск программы
python main.py

Управление
Левая кнопка мыши по свободной клетке — сделать ход.
Кнопка «Сдаться» — завершить партию.

Используемые технологии
Python
PyQt6
